# Registro de engenharia

Itens fechados durante a auditoria de 2026-11-04. O trabalho está no commit `feat(office): integrate Gemini and harden local workflows`; os testes executados constam ao fim desta seção. Pendências abertas ficam somente em [TODO.md](TODO.md).

- **HAB-005 — Integrar a terceira conta, Gemini CLI.** A conta, o histórico local e a presença confirmada por hooks entram no escritório Node e Docker. A instalação dos 7 hooks foi verificada nesta máquina. O cartão não apresenta cotas que a CLI não fornece ao Habblaud.
- **HAB-006 — Uma sala por projeto ativo.** Claude Code, Codex e Gemini CLI compartilham a sala ao usar o mesmo caminho de projeto. Caminhos Windows equivalentes deixam de criar salas duplicadas; nomes antigos dos personagens são migrados com conflitos preservados.
- **HAB-007 — Eliminar a janela preta na abertura.** Os dois atalhos Windows foram migrados para um lançador `pythonw.exe` que inicia a bandeja sem console; o reparo tem prévia, verifica propriedade dos atalhos e guarda backups locais. Abrir os dois atalhos não criou janela visível do Windows Terminal.
- **HAB-008 — Corrigir os cartões de uso.** Uma captura antiga do Claude deixa de aparecer como consumo atual e a orientação reconhece o mod já instalado. O Gemini mostra a consulta de cota na própria CLI, sem passos de instalação do Claude.
- **HAB-009 — Proteger dados e acesso local.** ACL restrita cobre tokens e configurações locais no Windows; uma porta Docker exposta não aceita rotas locais sensíveis por cabeçalho `Host` forjado. Respostas do World e clientes lentos do terminal têm limite de memória; pausa do World espera confirmação remota.
- **HAB-010 — Corrigir fluxos Windows e interface.** Abertura de links, anexos, cache de entregas, seleção de pasta, ditado e descoberta do Whisper recebem tratamento Windows e testes de regressão. Hooks locais funcionam com o terminal desativado. A CI inclui Windows.

Verificações finais: `npm run typecheck`, `npm run i18n:check` (3006/3006 em EN, ES e FR), `npm test -- --reporter=dot --silent` (1908 passaram, 16 ignorados), `npm run build`, `docker compose config --quiet`, `docker compose build --quiet`, `npm audit --audit-level=moderate` (0 vulnerabilidades) e `git diff --check` passaram. No navegador, três cartões apareceram sem erro de JavaScript; o Claude exibiu “—” para leitura antiga e o Gemini mostrou `/stats model`, também sem rolagem horizontal no celular. Os dois atalhos reparados foram abertos sem nova janela do Windows Terminal.

Limite verificado naquela rodada: uma sessão Gemini autenticada não pôde completar porque o arquivo `hosts` do Windows bloqueava o endpoint usado pela CLI. A investigação continuou na mesma sessão.

## 2026-11-04 — Continuação da integração Google

- **HAB-001 — Confirmar os hooks do Codex em `/hooks`.** O menu interativo mostrou os eventos instalados e ativos; no detalhe de `PreToolUse`, o comando do Habblaud estava habilitado e marcado `Trusted`. Verificado nesta máquina com Codex CLI 0.166.0; registrado no commit `feat(integrations): add Antigravity CLI and verify Windows workflows`.
- **HAB-011 — Liberar o endpoint bloqueado no Windows.** Com autorização do Lucas, removemos somente as oito linhas `cloudcode-pa` do arquivo `hosts` (linhas 36–43 antes da mudança). Backup completo e relido em `local/hosts-backups/hosts-20261105T012925Z.bak`, ignorado pelo Git. O domínio passou a resolver para endereços externos e a conexão TCP 443 funcionou. O teste real então revelou outro limite: o Google encerrou o login pessoal no Gemini CLI; a conta respondeu normalmente no sucessor Antigravity CLI (`agy`). Registro no commit `feat(integrations): add Antigravity CLI and verify Windows workflows`.
- **HAB-002 — Validar uma sessão Gemini CLI autenticada.** O teste real da conta pessoal retornou `IneligibleTierError`; conforme a comunicação do Google, ela migrou para o Antigravity CLI. Instalamos três hooks e a linha de status sem remover os hooks existentes. Uma sessão `agy --print` autenticada respondeu `OK`, criou um agente na sala do projeto e entrou no histórico local. Na TUI, a linha de status forneceu a identidade da conta e cinco grupos de cota; no navegador, o cartão exibiu uma porcentagem real. A correção para `transcript_full.jsonl` e para a chamada `cmd /c` no Windows tem testes de regressão. Fechado no commit `feat(integrations): add Antigravity CLI and verify Windows workflows` após build, testes e smoke Node/Docker.
- **HAB-012 — Atualizar o cartão de uso do Claude sem sessão aberta.** A conta padrão estava autenticada, mas o mod e o cache tinham leituras antigas. O cartão ganhou atualização sob demanda, por conta conhecida e apenas no servidor local, com limite de frequência e tempo. O teste real do botão retornou HTTP 200, atualizou o cache e exibiu a semana informada pelo Claude. A CLI não informou a janela de 5 horas; o cartão a identifica como indisponível sem reutilizar leitura antiga. A chamada fecha `stdin`, prevenindo o timeout reproduzido no primeiro smoke. Testes de CLI, HTTP e UI no commit `feat(integrations): add Antigravity CLI and verify Windows workflows`.
- **HAB-013 — Preservar a cota Google entre reinícios.** O statusline da TUI capturou cinco grupos reais, mas o servidor inicialmente os perdia ao reiniciar. Um cache local privado guarda apenas os campos de cota, plano, e-mail e horário; a UI mostra a idade da leitura. Após capturar uma nova leitura real e reiniciar duas vezes, o snapshot manteve os cinco grupos e o mesmo `fetchedAt`. Teste de whitelist/ACL e smoke no commit `feat(integrations): add Antigravity CLI and verify Windows workflows`.
- **HAB-014 — Estabilizar a suíte no Windows sob carga.** O runner agora limita a quatro workers; testes de integração com vários pedidos e comandos Git têm tempo total suficiente, enquanto as esperas específicas por eventos continuam limitadas. A suíte completa passou com 1.930 testes e 16 ignorados no commit `feat(integrations): add Antigravity CLI and verify Windows workflows`.

Verificações finais desta rodada: `npm run typecheck`, `npm run i18n:check` (3052/3052 em EN, ES e FR), `npm test -- --reporter=dot --silent` (1930 passaram, 16 ignorados), `npm run build`, `docker compose config --quiet`, `docker compose build --quiet`, `npm audit --audit-level=moderate` (0 vulnerabilidades) e `git diff --check` passaram. No navegador, os três cartões e a idade da leitura Google apareceram no desktop e no celular, sem erro de JavaScript nem rolagem horizontal. O botão Claude retornou HTTP 200 e atualizou o cache da conta sem abrir sessão.
